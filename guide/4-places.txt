4. Records, folders and views

Every file here is a record: a set of attributes, and for a file, some content. name, kind, folder, created and modified are always there, and you can add your own. A folder is a record whose kind is folder, and where a file lives is its folder attribute.

  attr readme.txt
  attr readme.txt tag=welcome
  ls | where $row.tag eq welcome

Because a folder is only a question, "which records have this folder?", any question about attributes can be a place too. in goes into one, and ls there lists everything that answers it, wherever it lives.

  in $row.kind eq text
  ls
  out

find asks once without going anywhere, and save-view keeps a question as a file you can go into later with in.

  find $row.kind eq folder
  save-view texts $row.kind eq text
  in texts
  out

The newest listing stays live: change something and it redraws. Tap live under it to stop it.
