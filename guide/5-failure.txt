5. When something fails

A failure is a value too, not a crash. A line that fails stops, changes nothing, and says why, with the kind of failure beside the message.

  read missing.txt

else runs something instead when the line before it fails:

  read missing.txt else echo "no such file"

try keeps the failure as a value, so it can be looked at:

  try read missing.txt | set problem
  $problem.kind
  $problem.message

?? gives a default when a stage answered nothing at all:

  first (ls | where $row.kind eq view) ?? "no views yet"

A line is all or nothing. If any part of it fails, nothing it did is kept.
