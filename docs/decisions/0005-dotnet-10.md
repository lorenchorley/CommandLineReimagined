# 0005. .NET 10 LTS, with dependencies managed centrally

| Field | Value |
| --- | --- |
| Status | Accepted, recorded retrospectively |
| Date | 2026-09-21 |

## Context

The solution targeted .NET 7, out of support, with .NET 8 for the web projects. The
owner asked for .NET 10 or the .NET 11 preview, and for every dependency to move at
the same time. Five test projects carried four different test framework versions.

## Options

1. **.NET 11 preview.** Newest, but the preview SDK could not be fetched from the
   build environment, and preview packages would have to be re-pinned at every
   preview.
2. **.NET 10.** The current long-term-support release, installable from the Ubuntu
   archive, with released versions of every dependency.
3. **Per-project versions, as before.** Keep versions in each project file.
4. **Central package management.** Versions in one `Directory.Packages.props`.

## Decision

Options 2 and 4. FParsec stays on its released 1.1.1 rather than the 2.0 beta, because
the parser's tests pin exact error columns.

## Consequences

The source generator had to move to the incremental API, which Roslyn 5 requires, and
its output became deterministic. Asset fingerprinting is off in the browser client so
republishing overwrites rather than accumulates.
